# 🏦 XYZ Bank Case Study

## 📌 Project Overview
This project is a simple banking web application developed using **HTML**, **CSS**, and **JavaScript**. It demonstrates basic web development concepts such as event handling, DOM manipulation, customer ID validation, and coupon generation.

## ✨ Features
- Welcome message on mouse hover
- Customer ID validation
- Coupon generation for valid customers
- Hide registration instructions
- Interactive user interface using JavaScript

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## 📂 Project Structure
```
XYZ-Bank-CaseStudy/
│── index.html
│── README.md
```

## 🚀 How to Run
1. Download or clone the repository.
2. Open the `index.html` file in any modern web browser.
3. Enter a valid Customer ID containing **XYZ**.
4. Validate the customer and generate the coupon.

## 📖 Concepts Demonstrated
- JavaScript Functions
- DOM Manipulation
- Event Handling
- String Operations
- Conditional Statements
